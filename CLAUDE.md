# Instrucciones del proyecto

## Documento de preguntas (`Tribial futbol galderak.md`)

- Respeta el formato y las reglas de redacción descritos en `README.md` («Cómo modificar las preguntas»).
- **No uses nunca punto y coma (`;`)** en preguntas, opciones ni explicaciones. Según el caso, usa `,`, `:` o `.`, para que el texto sea más fácil de entender. Antes de terminar un cambio, comprueba que el documento no contiene `;`.
- **Reparte las respuestas correctas entre las tres letras (`a)`, `b)`, `d)`) por igual o casi**, en el documento y dentro de cada categoría. Si al añadir o cambiar preguntas una letra queda claramente por encima o por debajo de las demás, reordena las opciones de algunas preguntas (cambiando también la línea `**Erantzuna:**`) para equilibrarlo.
- Después de cada cambio en el documento, regenera `js/dokumentua.js` con `node tresnak/eguneratu-galderak.js`.
